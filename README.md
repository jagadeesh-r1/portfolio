# Portfolio

Personal portfolio site for Jagadeesh Reddy Vanga — research engineer working on LLM architectures, production ML, and GenAI systems.

Live site: https://jagadeesh-r1.github.io/portfolio/

## Stack

Plain HTML, CSS, and vanilla JavaScript — no build step, no framework, no dependencies.

## Structure

- `index.html` — main landing page (hero, about, selected work, experience timeline, contact)
- `projects.html` — full projects listing
- `styles.css` / `script.js` — site styles and behavior
- `assets/` — images, resume PDF, and legacy CSS/JS

## Running locally

Serve the directory with any static file server, e.g.:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Static files are served directly via GitHub Pages from this repo.
